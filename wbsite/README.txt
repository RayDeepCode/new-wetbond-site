WetBond.com website files

To view: double-click index.html (or Main.dc.html). Everything runs from this folder.
If a browser shows a blank page, open Terminal in this folder and run:
  python3 -m http.server 8000
then visit http://localhost:8000

Contents: 40 pages (.dc.html), support.js (runs the interactive parts), assets/ (134 images and 2 videos).
Forms still open email until they are connected to GoHighLevel. See the Launch Master Plan.
